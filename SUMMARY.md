## 📋 Что находится в outputs

### 1️⃣ HTML-шаблоны для каруселей

#### `n8n_carousel_code.js` — 5 "продающих" шаблонов
- **The Lifestyle** — фото слева, текст справа
- **The Quote** — цитата в центре, фото фоном
- **The Split** — 50/50 фото + чек-лист
- **The Overlay** — фото + текст оверлей снизу
- **The Cards** — 3 фото + инфо снизу (светлый фон)

**Функции:**
- 5 встроенных тем (ocean, desert, forest, rose, dark)
- Легко добавлять новые темы
- Переменные плейсхолдеры ({{DESTINATION}}, {{PHOTO}} и т.д.)

**Как использовать:** Копируй код в n8n Code-ноду → выход: `html` → идёт в API

---

#### `n8n_diary_carousel.js` — 6 "дневниковых" шаблонов
- **Cover** — обложка с polaroid-рамкой
- **Single Box** — фото + 1 номерной бокс
- **Duo** — 2 фото вертикально + 2 бокса
- **Trio** — коллаж 3 фото + 1 бокс
- **Two Box** — фото + 2 бокса
- **Center** — вопрос по центру + хэндл

**Функции:**
- Белые рамки с номерацией (как в инстаграм-сторис)
- 3 встроенные темы (white, gold, dark)
- Polaroid-эффект на обложке

**Как использовать:** Как выше, но для дневников/storytelling постов

### 2️⃣ Railway API сервис

#### `railway_service.tar.gz` — готовый cloud-сервис

**Содержит:**
```
railway_service/
├── server.js              ← Express сервер (100 строк кода)
├── package.json           ← Зависимости (express, playwright)
├── .gitignore
├── QUICK_START.md         ← Старт за 5 минут
├── README.md              ← Полная документация
└── N8N_SETUP.md           ← Как подключить в n8n
```

**Эндпоинты:**
- `POST /convert` — HTML → Base64 PNG
- `POST /convert-file` — HTML → Binary PNG (для скачивания)
- `POST /batch` — Несколько HTML → все PNG сразу
- `GET /` — Health check

**Развертывание:** GitHub → Railway → 2 клика → готово за 5 минут

## 🔧 Полный workflow (от идеи до публикации)

### Вариант 1: На базе ТВОИХ данных (для клиентов)

```
[Туристический пакет]
  ↓ (название, фото, дату, цену)
↓
[n8n: Code-нода]
  Подставляешь в n8n_carousel_code.js или n8n_diary_carousel.js
  Выход: HTML (1080x1080)
  ↓
[n8n: HTTP Request]
  POST на https://твой-домен.up.railway.app/convert
  ↓
[n8n: Write Binary File / Upload to Cloud]
  Сохраняешь PNG → Google Drive / AWS S3 / Telegram
  ↓
[Отправляешь клиенту]
  "Вот 6 готовых слайдов для твоей каруселя в Instagram"
  ↓
[Клиент публикует]
  Готово! 📸
```

### Вариант 2: Массовая генерация (для своего контента)

```
[Таблица Google Sheets с турами]
  Столбцы: destination, tagline, dates, days, price, photo
  ↓
[n8n: Google Sheets trigger]
  Каждый день в 9:00 читает новые туры
  ↓
[n8n: Loop по строкам]
  Для каждого тура:
    - Генерируешь 6 слайдов (дневник)
    - Отправляешь на API
    - Получаешь 6 PNG
    ↓
[n8n: Автопубликация]
  Публикуешь в Instagram / Facebook / TikTok через Buffer/Meta API
  ↓
[Ready 24/7]
  Каруселя генерируется и публикуется автоматически
```

  ]

## 🔒 Безопасность (когда будешь продавать)

**Добавь API Key в server.js:**
```javascript
const API_KEY = process.env.API_KEY; // задаёшь в Railway env vars
app.use((req, res, next) => {
  if (req.headers['authorization'] !== `Bearer ${API_KEY}`) {
    return res.status(401).json({ error: 'Unauthorized' });
  }
  next();
});
```

**В n8n:**
```
Headers: Authorization: Bearer твой_secret_key
```
